# GeoStamp Camera

Takes photos and burns your custom text, date/time, GPS coordinates and address onto them.
Saved to Pictures/GeoStamp.

## Get the APK
1. Create a new GitHub repo and push this folder (including the `.github` folder).
2. Open the repo's Actions tab, run "Build APK" (it also runs on every push).
3. Download the `GeoStamp-apk` artifact, unzip it, install `app-debug.apk` on your phone.

Or open the folder in Android Studio and press Run / Build APK.

Address lookup needs internet; GPS coordinates work offline.
